How to set up Pip

Pip is made for Windows. His optional AI chat runs locally through Ollama.

1. Get Ollama

Download Ollama from its official website:

Download Ollama ↗

2. Get Pip's AI model

Open Command Prompt and enter:

ollama pull llama3.2:3b

3. Open Pip

Once the verified Pip release is available, extract the download and open Pip's application.

4. Say hello!

Right-click Pip to chat. Left-click him for a silly message. And don't forget the bread!

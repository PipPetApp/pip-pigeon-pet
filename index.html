Getting Pip ready

Pip needs Ollama for his AI chat. Here's how to set it up.

1. Install Ollama
Get Ollama from ollama.com/download.
2. Get Pip's AI model
Open Command Prompt and enter:
ollama pull llama3.2:3b
3. Open Pip!
Once the download is ready, start Pip and enjoy your new desktop friend.

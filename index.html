Getting Started

For the Python Edition, you'll need:

  • Windows 10 or Windows 11
  • Python 3.10 or newer
  • Ollama
  • The Ollama model: llama3.2:3b

Once Ollama is installed, open Command Prompt and run:

ollama pull llama3.2:3b

More detailed installation instructions are included in the downloaded Python Edition.
